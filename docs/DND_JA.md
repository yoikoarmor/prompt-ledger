# ドロップとフォルダ入力

PNG/JPEG/JSONはページ内のどこに落としても選択できます。領域外に落としたファイルを
ブラウザが開いてしまう既定動作を抑止し、選択件数を表示します。クリックでのファイル選択も使えます。
ブラウザ内の画像やリンクのドラッグにはローカルFile実体がない場合があります。その場合は
理由を表示し、現在の選択を保持します。対応形式が混在する場合は未対応件数を表示します。

親フォルダ `img` を落とすか「フォルダを選択」で選ぶと、
`img/imgfolder1/a.png` と `img/imgfolder2/b.json` などの下位フォルダも含みます。
ドロップではFile and Directory Entries APIを使い、readEntriesを空になるまで繰り返します。
最初の100件だけで打ち切りません。対応しないブラウザでは専用のフォルダ選択を使ってください。
相対パスは親フォルダ名を含めて取込・比較なし抽出へ渡します。選択しただけでは送信・推論しません。

処理中の再ドロップは現在の処理を保持して案内します。フォルダ列挙中も中止できます。
列挙エラー・中止・循環・範囲外を示すパスを検出した場合は、その選択全体を採用せず以前の選択を保ちます。
ファイル名のdot segment、区切り文字、絶対パス、繰返しentry/pathを拒否します。
不正な循環が異なるパスとして伸び続ける場合にも止まるよう、ドロップ列挙は128階層を安全上限とします。
これは件数やファイルサイズの上限ではありません。

ブラウザのFile/Entry APIはOSのリンク対象をすべて開示しません。fullPathが別の範囲を示す参照や
検出可能な循環は拒否しますが、あらゆるOS/ブラウザのsymlink/junctionをアプリだけで識別できる保証はありません。
リンクを含まない選択フォルダを推奨します。Windows上の今回の実ブラウザのフォルダ選択では、
隔離した合成junction（外側フォルダ参照・自己参照）は選択に混入しませんでした。
OSからの実ドラッグ操作によるjunctionの動作、他のブラウザ/OSは未検証です。
CLIは従来どおり入力root内のcontained検証でsymlink/junctionを拒否します。

大規模な選択はFile参照と相対名の一覧を保持します。画像bytesを配列へ全件展開する方式ではありませんが、
選択一覧のメモリは件数に依存します。モデルtoken長やmetadata安全予算、比較ルールは変更していません。
